## 🐛 Investigasi: Death Animation Floating
- Ditemukan masalah pada animasi `base_death`: karakter tidak jatuh ke tanah melainkan **melayang di udara** saat animasi diputar di scene.
- Root cause: posisi bone `Hips` di-bake dari koordinat dunia Blender ke dalam animation track, sehingga animasi bergerak relatif dari ketinggian standing pose (bukan dari ground).
- Solusi: menggunakan **custom track** (Save to File + Keep Custom Tracks sudah aktif) untuk mengoverride posisi node parent agar karakter turun ke ground.

## 📚 Pemahaman Baru: Sistem Animasi Import Godot
- Memahami bahwa **imported bone tracks tidak bisa diedit langsung** di Godot — perubahan tidak akan tersimpan saat reimport.
- Solusi yang benar: aktifkan **Save to File** + **Keep Custom Tracks** di Advanced Import Settings untuk animasi yang perlu dimodifikasi, lalu tambah **custom track** di atas animasi yang di-import.
- Animasi `base` library (`base_attack.res`, `base_death.res`, dll.) sudah dikonfigurasi dengan Save to File aktif.
